## Agent Brief

**Category:** bug
**Summary:** Only one monster species per tier ever spawns; the RNG is used only for the unique-prefix roll.

**Current behavior:**
`spawn_monster` filters all monster defs for the target tier and takes the
first one, so each tier always yields the same species (e.g. tier 1 is always
the first tier-1 def).

**Desired behavior:**
Monster spawning picks a uniformly random def among all defs of the tier.

**Key interfaces:**
- `spawn_monster` in the monster module: use the RNG's `pick` over the tier's
  def list; keep a fallback to the first def if the pick comes back empty
  (`pick` returns `Option`)

**Acceptance criteria:**
- [ ] Repeated spawns at a tier with multiple defs produce more than one species
- [ ] Spawn fallback path still compiles and is only hit when the tier list is empty
- [ ] Existing unique-prefix / elite rolls are unchanged

**Out of scope:**
- Per-tier spawn weighting, elite rolls beyond the existing unique prefix
  (see issue 19)
