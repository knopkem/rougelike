## Agent Brief

**Category:** bug
**Summary:** The score screen always reports death by "slain" on 1970-01-01; the actual killing blow and run date are never tracked.

**Current behavior:**
`score_info` returns a hardcoded `DeathCause::Slain` and the literal date
"1970-01-01". Nothing records what actually killed the player (monster,
starvation, poison), and the run date is never computed.

**Desired behavior:**
The game records the last damage source (and its identity, e.g. the monster's
name) whenever the player takes damage, and `score_info` reports the true cause
of death plus a real in-game date derived from the run's turn count.

**Key interfaces:**
- `Game`: a last-damage-source field, updated by every player-damage path
  (monster attack, starvation, poison tick, and any other damage source)
- `score_info`: derive the reported `DeathCause` and date from that state
- The `DeathCause` enum: existing variants; extend only if a needed cause is missing

**Acceptance criteria:**
- [ ] Death by a monster reports the slain cause with the monster identifiable
      in the score/hiscore line
- [ ] Death by starvation reports the starvation cause
- [ ] Death by poison reports the poison cause
- [ ] The reported date reflects the actual in-game date, not a constant

**Out of scope:**
- Hiscore file format changes beyond what the cause/date already carry
