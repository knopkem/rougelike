## Agent Brief

**Category:** bug
**Summary:** Autosave runs after the death/victory turn and re-writes a save the game just deleted, so a dead game can be loaded.

**Current behavior:**
The main loop unconditionally calls `save::autosave(game)` after every turn,
including the turn on which the player dies or wins. The death/victory checks
delete the autosave, then main re-writes it with `alive = false` / `won = true`.
The title screen shows "Continue" whenever an autosave file exists, offering an
unplayable dead game.

**Desired behavior:**
Autosave only happens for a live, ongoing run. After death or victory no
autosave file exists and the title screen offers no "Continue" entry.

**Key interfaces:**
- `save::autosave`: guard the write so it is a no-op (or is not called) when the
  game is dead or won
- The main loop's per-turn save step
- Title-screen "Continue" visibility: must reflect only loadable, playable
  autosaves

**Acceptance criteria:**
- [ ] After the death turn, no autosave file remains on disk
- [ ] After the victory turn, no autosave file remains on disk
- [ ] A mid-run autosave still writes normally
- [ ] Title screen hides "Continue" when no valid autosave exists

**Out of scope:**
- The hiscore path (see issue 01)
- Save file format changes
