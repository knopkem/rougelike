## Agent Brief

**Category:** enhancement
**Summary:** The player starts with an empty inventory and no weapon; PLAN specifies class-appropriate starting kits.

**Current behavior:**
New players get no items: no wielded weapon, no armor, no rings, no potions —
only starting gold. The player fights unarmed (1d4 after issue 06 lands).

**Desired behavior:**
Per PLAN's kit table, a new player of a given class starts with that class's
kit: the appropriate weapon, armor, and consumables, with kit-specific perks
where PLAN defines them.

**Key interfaces:**
- Player construction: apply the class's kit to the new player
- The class/race model: whatever the current class field drives the kit
  selection; if class selection itself is not yet implemented, use the
  planned default class and keep kit selection a pure function of class
- Item definitions: kits reference existing item defs; add defs only if a kit
  item is missing (e.g. a basic weapon per class)

**Acceptance criteria:**
- [ ] A new game's player has the kit items in inventory/equipped per PLAN's
      table for their class
- [ ] The starting weapon is wielded and the starting armor worn
- [ ] Kit contents are defined in one data-driven place
- [ ] A save/load round-trip of a fresh game preserves the kit

**Out of scope:**
- Class/race *selection* UI (if that work is separate); this issue assumes the
  class exists as data
- Kit-specific perks beyond what PLAN lists
